# Qalio Platform

Qalio is a full-stack talent assessment and recruitment management platform.

## Architecture

- **`qalio-frontend`**: Next.js (React, TypeScript, TailwindCSS, Turbopack) web application interface.
- **`qalio-backend`**: Node.js (Express, TypeScript, MongoDB) API server with WebSocket support.

## Getting Started

### 1. Backend Setup
```bash
cd qalio-backend
npm install
npm run dev
```

### 2. Frontend Setup
```bash
cd qalio-frontend
npm install
npm run dev
```

The frontend will run on `http://localhost:3000` and the backend will run on `http://localhost:4000`.
